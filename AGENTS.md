# Beamer lecture work

Read `Beamer_Lecture_Improvement_Project.md` and `automation/lecture_prompt.md` before working on a lecture. The maintainer selects the lecture and mode. Follow the selected mode and produce the four reports, including when compilation is blocked.

Keep `marco.tex`, the original lecture source and PDF, and original figures intact. In revise mode use a complete `_revised.tex` copy and preserve the original project paths, page geometry, theme, section order, frame labels, and overlays. Preserve official course descriptions and policy. Confirm administrative changes with the maintainer. Record figure proposals without generating assets.

Build with XeLaTeX using the original dependencies. Require a successful build and visual verification before releasing a revised PDF.
